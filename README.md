# Okdesk Clearbat Launcher

Расширение добавляет кнопки запуска CLEAR.bat рядом с доступами оборудования на `https://aqba.okdesk.ru/`.

## Структура

- `chrome/` - версия для Google Chrome.
- `edge/` - версия для Microsoft Edge.
- `firefox/` - версия для Mozilla Firefox.

## Загрузка в Chrome

1. Открой `chrome://extensions/`.
2. Включи режим разработчика.
3. Нажми `Загрузить распакованное расширение`.
4. Выбери папку `chrome`.

## Загрузка в Edge

1. Открой `edge://extensions/`.
2. Включи режим разработчика.
3. Нажми `Загрузить распакованное`.
4. Выбери папку `edge`.

## Загрузка в Firefox

1. Открой `about:debugging#/runtime/this-firefox`.
2. Нажми `Загрузить временное дополнение`.
3. Выбери файл `firefox/manifest.json`.

Временное дополнение Firefox пропадает после перезапуска браузера.
