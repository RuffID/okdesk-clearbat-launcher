# Okdesk Clearbat Launcher

_v. 1.3_

Расширение для Okdesk, которое на странице заявки показывает панель **«Быстрый запуск»** с кнопками
iikoOffice, iikoChain, Ассистент, RustDesk и AnyDesk

Панель собирает доступы из трёх мест:

- карточка **клиента** (компании);
- карточка **объекта обслуживания**;
- карточки **оборудования**, привязанного к заявке.



Pop-up для быстрого выбора доступа до нужного доступа/сервера из заявки

- работает на странице заявки;
- показывает одну компактную панель со всеми доступами по клиенту, объекту и оборудованию;
- объединяет данные: например, адрес сервера может быть в карточке объекта, логин iiko — в карточке
  клиента, а RustDesk/AnyDesk — в карточке конкретного оборудования
- умеет обновлять данные кнопкой `⟳` и сворачиваться кнопкой `−`.

## Установка

### Chrome, Edge, Яндекс Браузер

1. Откройте страницу расширений:
   - Chrome: `chrome://extensions/`;
   - Edge: `edge://extensions/`;
   - Яндекс Браузер: `browser://extensions/`.
2. Включите режим разработчика.
3. Нажмите **«Загрузить распакованное расширение»**.
4. Выберите папку `chrome` из этого архива.
5. Откройте или обновите страницу заявки в Okdesk.

### Firefox

1. Откройте `about:debugging#/runtime/this-firefox`.
2. Нажмите **«Загрузить временное дополнение»**.
3. Выберите файл `firefox/manifest.json`.

Временное дополнение Firefox исчезает после перезапуска браузера — это ограничение Firefox.

## Как пользоваться

1. Откройте заявку в Okdesk, например `https://aqba.okdesk.ru/issues/549714`.
2. Поверх страницы появится плавающая панель **«Быстрый запуск»**.
3. В строках будут клиент, объект и каждое оборудование из заявки.
4. Нажмите нужную иконку:
   - iikoOffice;
   - iikoChain;
   - iikoWeb (иконка Internet Explorer, открывается в новой вкладке браузера);
   - Ассистент;
   - RustDesk;
   - AnyDesk.

Панель можно перетащить за заголовок в удобное место. Положение запоминается.
Двойной клик по заголовку возвращает панель в правый верхний угол.
Кнопка `−` сворачивает панель, `⟳` — перечитывает карточки, `?` — показывает диагностику
(типы элементов полей, количество найденных карточек и коды ошибок чтения), её можно скопировать для отладки.

По умолчанию включён **компактный вид**: панель уже, строки ниже, служебные подписи скрыты.
Кнопка `▤` / `▥` в заголовке переключает компактный и обычный вид; выбор запоминается.

Кнопка `⚙` открывает настройку расположения иконок:

- **Авто (по названию)** — как сейчас: иконки справа, если помещаются, иначе переносятся вниз;
- **Всегда справа** — иконки в одну строку с названием, длинное название сокращается;
- **Всегда снизу** — иконки отдельной строкой под названием.

Выбор запоминается.

Активные иконки цветные, недоступные — серые. Наведите курсор на серую иконку, чтобы увидеть,
в какой карточке не хватает данных.

При первом запуске браузер может спросить разрешение на открытие внешнего приложения
`CLEAR.bat`. Нужно разрешить.

## Какие поля читаются

Расширение ищет дополнительные параметры по кодам и по названиям полей.

| Кнопка | Коды параметров | Названия полей (примеры) |
|---|---|---|
| AnyDesk | `AnyDesk`, `anydesk`, `any_desk` | `AnyDesk` |
| Ассистент | `AC`, `assistant` | `Ассистент`, `Assistant` |
| RustDesk | `rust`, `rustdesk`, `rust_desk` | `RustDesk`, `Rust Desk` |
| iikoOffice | `srv_addr`, `iikooffice`, `iiko_office` | `Адрес сервера`, `Сервер iiko`, `iikoOffice` |
| iikoChain | `0017`, `iikochain`, `iiko_chain` | `iikoChain`, `Chain`, `Чейн` |
| iikoWeb | `iiko_web`, `iikoweb`, `iiko_web_link`, `iiko_web_url` | `Ссылка на iiko WEB`, `iiko WEB`, `iikoWeb` |
| Логин/пароль iiko | `0008`, `iiko_login`, `iiko_password` | `Iiko логин/пароль`, `Iiko логин`, `Iiko пароль` |

Форматы значений:

- AnyDesk, Ассистент, RustDesk: `идентификатор` или `идентификатор / пароль`
  (можно использовать обратный слеш `\`);
- iikoOffice / iikoChain: `host`, `host:port`, `https://host` или `host:port/пароль`;
- iiko-логин: `login / password`.

Если значение не заполнено или стоит заглушка `-`, `[не указано]`, `Нет`, кнопка будет неактивна.

## Как это работает

1. Расширение находит в заявке клиента, объект и **все строки оборудования**, включая случаи, когда
   название оборудования — обычный текст, а ссылка на карточку спрятана в иконке-лупе.
2. Загружает карточки с того же домена Okdesk (с текущей сессией и сертификатом браузера).
3. Достаёт дополнительные параметры оборудования/объекта/клиента.
4. Собирает ссылку `clearbat:` в формате CLEAR.bat v6.6+:
   `clearbat:/<base64>?encode=full`.
5. По клику открывает ссылку через обработчик протокола `clearbat:`.

## Совместимость

- Нужен установленный и настроенный **CLEAR.bat** (v6.6 или новее), который регистрирует протокол
  `clearbat:`.
- Браузер должен разрешать открытие внешних приложений.
- За один раз читается не более 8 карточек оборудования — этого достаточно для типовой заявки.
- Если в карточке оборудования нет ссылки на карточку (например, интерфейс открывает её только
  модальным окном без `href`/`data-url`), доступы этого оборудования прочитать не получится.
- Расширение рассчитано на домены `aqba.okdesk.ru` и `help.aqba.ru`

## Если панель не появилась

1. Проверьте, что открыта именно страница заявки: в адресе есть `/issues/<номер>`.
2. Проверьте, что расширение включено и ему разрешён доступ к `aqba.okdesk.ru`.
3. Обновите страницу (F5).
4. Откройте консоль браузера (F12) и посмотрите ошибки.

## Если доступы не найдены

1. Откройте карточку оборудования из заявки.
2. Проверьте, что в дополнительных параметрах заполнены нужные поля (AnyDesk, RustDesk, Ассистент,
   адрес сервера, Iiko логин/пароль).
3. Вернитесь в заявку и нажмите `⟳` в панели.
